# Project lessons

- 2026-08-26 — shadcn v4 expresses the requested `base-nova` setup as `--preset nova --base base`; the resulting `components.json` style remains `base-nova`.
- 2026-08-26 — Serwist injects a webpack config even when disabled. Next.js 16 therefore needs an explicit `next dev --turbopack`; production PWA generation remains `next build --webpack`.
- 2026-08-26 — The Cloudflare target is the `daiko` account and only the `webpiano.xyz` apex custom domain. `www` is intentionally absent.
- 2026-08-26 — Cloudflare validates compatibility dates in UTC. While local time was already August 26, `2026-08-26` was rejected as future-dated, so the initial deploy uses `2026-08-25`.
- 2026-08-26 — `/` is the playable instrument, not a marketing LP. Keep PC-keyboard, pointer, sustain, and audio state separated, and release voices only after the final input source for a MIDI note ends.
- 2026-08-26 — Keep every test below `tests/`: isolated logic in `tests/unit`, rendered and repository contracts in `tests/integration`, browser journeys in `tests/e2e`, and Bun DOM setup in `tests/support`.
- 2026-08-26 — Do not fork `/` into PC and smartphone products. Keep one responsive touch-capable instrument, optimize installed mobile use for landscape, and reserve `/pedal/[sessionId]` for QR-paired remote sustain.
- 2026-08-26 — Sustain sources remain independently owned. Space toggles the persistent manual lock, the remote pedal remains momentary, and DataChannel loss removes only the remote source within the 750ms deadman window.
- 2026-08-26 — Keep request/response operations in tRPC + TanStack Query, but keep signaling in the Cloudflare native Hibernation WebSocket because tRPC's WebSocket adapter targets Node `ws`. Share Valibot wire schemas across browser and Durable Object.
- 2026-08-26 — Next dev cannot load a Durable Object class exported by the custom OpenNext Worker. Use `bun run dev` for the responsive instrument and `bun run preview` for the full tRPC/DO/WebRTC pairing flow. The server-owned `PEDAL_ALLOW_STUN_ONLY` setting permits direct local/LAN/production connectivity; TURN remains an optional reliability fallback.
- 2026-08-26 — Cloudflare Builds and clean CI do not have the gitignored `cloudflare-env.d.ts`; run `wrangler types` before quality and OpenNext builds. Release through a PR merged to `main`, then let the connected Cloudflare Build run `cf:build` and `cf:deploy` automatically.
- 2026-08-26 — Keep the standard 32-note single keyboard as `/`'s first view. Dual Range is opt-in, uses a correctly proportioned 88-key navigator plus two enlarged hand ranges, and resets input ownership before layout changes while retaining range settings only for the current page session.
- 2026-08-26 — Every UI change starts with desktop and affected-mobile wireframes generated from the current rendered UI under `docs/wireframes/`; portrait phone access to `/` is an orientation guide, not a compressed instrument.
- 2026-08-27 — Prevent layout shift across the application: async and conditional content reserves its final dimensions and uses same-geometry shadcn Skeletons. The phone-pedal dialog keeps one fixed-height slot from session creation through QR readiness.
- 2026-08-27 — Piano ranges are MIDI-start based, not octave-number based. Standard and Dual Range move by semitone; Dual Range overlays drag with a preview and commit only on pointer release after input ownership is cleared.
- 2026-08-27 — Cloudflare native version preview URLs do not support Workers that implement Durable Objects. PR previews therefore deploy branch-scoped `webpiano-pr-*` Workers through the existing non-production Workers Build, while GitHub waits for and comments the deterministic workers.dev URL.
- 2026-08-27 — Standard and Dual Range share one A0–C8 navigator: Standard renders one gauge and Dual renders LOWER/UPPER gauges. Header icons represent Pedal, Dual Range, and Sound without a duplicate visual sustain control.
- 2026-08-27 — Keyboard mode is an explicit `SINGLE | DUAL` exclusive toggle, not an action-labeled button. Sound is a real Mute/Unmute toggle that changes the voice output gain and icon without changing mode or sustain ownership.
- 2026-08-27 — Keep the PWA Install trigger mounted in a fixed-width header slot. Capability detection only replaces a reserved Drawer content area with a same-geometry Skeleton, native prompt, platform instructions, or installed state; it must never shift the instrument header.
